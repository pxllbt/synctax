# Security Policy

## Supported versions

| Version | Status |
| --- | --- |
| 1.0.x   | Current, receiving updates |

## What to know

Synctax is a config-only theme — it's TOML color values, YAML metadata, and static image files. No shell scripts, no binaries, no executable hooks. The wallpapers are standard PNG/JPEG, nothing custom-decoded.

That said, a corrupted asset or a bad color value can break your desktop. If something looks off, report it.

## Reporting a problem

Don't open a public issue if it's security-sensitive. You can:

1. Open a [private security advisory](https://github.com/pxllbt/synctax/security/advisories/new)
2. Or message me through GitHub

Include what you saw and what you expected. Thanks for looking out for the project.
